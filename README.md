# Project_Organizer

Project title: 
  Project Organizer

Team members: 
  Charley Madlock, Jack Simon

Current Prototype: 
  We made a website that you can go onto if you want to organize a plan for a book or for a school project. We have a login page that takes you to your already saved projects and if you do not have an account then we have a create account page where you can make your own account. 

Major pages or features currently implemented:
  Major pages- login, create account, storyboard, college project, saved projects
  Major features- Seasonal button, the nav bar

Instructions for running the prototype:
  When you are on the login page, you need to type c in the username and project in the password to act like those are your login information. When you go onto the create account page put Jack into the name section, J into the username section, and dog into the password. If you click the seasonal button, then it will change the colors from blue and white to orange and purple because it is almost Halloween. This will change depending on the time of the year.

Any features that are currently simulated using static or dummy data:
  We have a fake login username and password so that you can see what it will look like once we have the database. We also have a fake avatar in the corner, it will show the first letter of your name when you create an account. 

What your team plans to work on next:
  Next we will work on making a drop down so that you can login, or logout. We also plan on making it so that if you click the seasonal button, then it will stay in seasonal mode when you change which page you are on.
